# civileanrp-legal
1. Información que recopilamos
Para el correcto funcionamiento de sus comandos y sistemas, CivileanRP puede recopilar y almacenar temporalmente los siguientes datos proporcionados por la API de Discord:
• IDs de usuario de Discord, nombres de usuario y roles asignados.
• IDs de servidores y canales donde se ejecuta el bot.
• Registros básicos de comandos utilizados o datos vinculados a la cuenta del juego (en caso de vinculación con el servidor).
2. Uso de la información
Los datos recopilados se utilizan exclusivamente para:
• Ejecutar las funciones solicitadas por los usuarios dentro del servidor.
• Mantener la seguridad, moderación y sincronización de roles o permisos.
• Mejorar el rendimiento y corregir errores técnicos.
3. Compartición y almacenamiento de datos
No vendemos, alquilamos ni compartimos tu información personal con terceros. Los datos se almacenan en servidores seguros con acceso restringido únicamente al equipo de desarrollo de CivileanRP.
4. Eliminación de datos
Si deseas solicitar la eliminación de los datos asociados a tu cuenta de Discord, puedes contactar al equipo de administración en el servidor oficial de Discord de CivileanRP y procesaremos tu solicitud a la brevedad.
